# MacBook ISO Patcher 0.1.3

## Changes

- Accept all languages and client editions of Windows 10 x64, builds 19041–19045, including French and single-edition or multi-edition WIM/ESD media.
- Check the 2016 A1706 GPU's device status and Intel service binding directly instead of searching for English text in Windows Setup diagnostics.
- Copy DisplaySwitch's available localized resources with its executable from the same Windows image. Prefer an image matching Setup's language when one is selected.
- Preserve the source ISO's edition-configuration channel and volume-license settings, and verify that selected editions retain their language, architecture and build metadata.
- Show edition language codes and present ISO compatibility details as bullet points.
- Clarify model testing labels and README model ordering. MacBookPro14,2 remains ready for testing and unverified.
- Update the app and Windows executable version to 0.1.3.

## Download

Run **MacBookISOPatcher-0.1.3.exe** on 64-bit Windows.

## Compatibility and validation

The hardware-verified reference remains English (US) Windows 10 Pro on the headless 2016 A1706. Localized media, additional editions, and newly generated ISOs still need boot/install testing on the target Mac. The other model recipes remain unverified.

Older Windows 10 builds, Windows 11, ARM/x86 and split SWM images remain unsupported. Original source ISOs are not modified.

The release executable compiled successfully. Automated tests were not run for this release preparation. A successful release compilation does not establish boot or installation compatibility.
