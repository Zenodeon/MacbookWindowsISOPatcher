# MacBook ISO Patcher 0.1.4

## Fixes

- Fix Windows 10 Enterprise LTSC media being rejected when its edition configuration uses the Volume channel. Preserve its channel and volume-license settings.
- Fix the false **Output edition mapping mismatch** at step 9 when DISM refreshes a Windows 10 image's reported build number during servicing, such as 19041 to 19044 for LTSC 2021. Output checks still confirm the selected edition, language, architecture, installation type and image index.
- Reject ISOs containing no compatible Windows editions during ISO scanning, before starting a build. The existing Windows 10 x64 build-range checks remain in place.
- Save the original build failure in the retained build log, with file paths and more detailed staging errors. Edition-mapping failures now show the expected and actual metadata.
- Remove the lengthy “Retry starts from step 1” explanation from build-error popups and simplify the stopped-build message.
- Update the app and Windows executable version to 0.1.4.

## Download

Run **MacBookISOPatcher-0.1.4.exe** on 64-bit Windows.

## Compatibility and validation

Supports Windows 10 x64 client editions, builds 19041–19045, in all languages, with single-edition or multi-edition WIM/ESD media. Older Windows 10 builds, Windows 11, ARM/x86 and split SWM images remain unsupported.

The French LTSC 2021 source ISO was inspected, and retained build metadata confirmed the 19041-to-19044 change behind the false mapping error. A complete patched-ISO build and a hardware boot/install test with these fixes have not been completed. Automated tests were not run for this release preparation.

The hardware-verified reference remains English (US) Windows 10 Pro on the headless 2016 A1706. Other languages, editions and model recipes still need testing on the target Mac. Original source ISOs are not modified.
