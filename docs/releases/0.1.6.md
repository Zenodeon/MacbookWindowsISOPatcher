# MacBook ISO Patcher 0.1.6

## Changes

- Prepare USB from the completion page: copy the completed ISO to an existing Ventoy USB, verify the copy and enable USB setup logging.
- Show copy/verification progress, cancellation and existing-file choices: replace after confirmation, keep both or cancel. Existing files are preserved until the new copy is verified.
- Retry logging-marker failures without copying the ISO again. Reopen the dialog to see an ongoing operation or its result.
- Keep a manual route for opening the ISO folder, copying the ISO yourself and enabling logging separately.
- Add a sidebar USB logging dialog, available without a completed build or selected model.
- Simplify the completion guide into six sections with numbered substeps, including Option/Alt startup, EFI Boot/Ventoy selection, WIMBOOT and Windows Setup troubleshooting.
- Update the instructions included in newly built ISOs and improve README readability.

## Download

Run MacBookISOPatcher-0.1.6.exe on 64-bit Windows. The versioned EXE is the only uploaded asset; no ZIP is needed.

Set up Ventoy separately before using Prepare USB. The patcher does not install Ventoy or format your USB.

## Validation and compatibility

194 automated tests passed. Formatting, Clippy with warnings as errors and the optimized Windows build passed. Actual debug UI captures were reviewed in both themes at 1240 x 700 and 800 x 520.

USB-copy tests used disposable files and simulated volume/marker fixtures. They cover verification failures, conflicts, cancellation, changed files, insufficient space, file-size limits, simulated removal, read-only storage, locked files and redirected paths. Physical Ventoy USB copying, exFAT behavior and real unplug/reconnect testing remain pending.

Windows-source support and model recipes are unchanged from 0.1.5. Supports Windows 10 x64 client builds 19041–19045 with WIM/ESD media. The hardware-verified reference remains the headless 2016 A1706; other models and newly generated ISOs require testing on the target Mac. The previously recorded host DISM Error 87 limitation remains unresolved. No full ISO rebuild or Mac hardware test was performed for this release.
