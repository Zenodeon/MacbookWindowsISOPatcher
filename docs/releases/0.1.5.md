# MacBook ISO Patcher 0.1.5

## Changes

- Add the 21.5-inch 2017 Core i5 iMac (iMac18,1, Iris Plus 640) as an Unverified testing profile.
- Choose Built-in screen or External screen inside the iMac card. The choice controls Windows Setup and is retained in jobs, diagnostics and issue drafts. External is the default.
- Use pinned Intel 27.20.100.9316 and Apple Boot Camp 041-88735 for the iMac, with model-specific startup drivers and USB support logs.
- Include the 0.1.3 and 0.1.4 updates: all-language Windows 10 media, localized DisplaySwitch resources, structured A1706 graphics readiness, LTSC Volume-channel preservation and corrected post-servicing edition validation.
- Preserve the selected display target while copying localized Setup display resources.

## Download

Run MacBookISOPatcher-0.1.5.exe on 64-bit Windows. The versioned EXE is the only uploaded asset; no ZIP is needed.

## Compatibility and validation

Supports Windows 10 x64 client editions, builds 19041–19045, in all languages, with single-edition or multi-edition WIM/ESD media. Older Windows 10 builds, Windows 11, ARM/x86 and split SWM images remain unsupported.

174 automated tests passed, including regression checks for French LTSC build metadata, Volume-channel/UTF-16 configuration, localized display resources and iMac screen selection. Formatting and Clippy with warnings as errors passed; the optimized Windows x64 EXE was rebuilt from the combined source.

The iMac's real pinned packages previously passed production extraction. Its disposable WinPE servicing probe encountered host DISM OS-provider error 87 before model-specific configuration. Full offline servicing/persistence and boot/install testing on the actual iMac remain unconfirmed. Both iMac screen modes remain Unverified.

The hardware-verified reference remains English (US) Windows 10 Pro on the headless 2016 A1706. Other models, languages, editions and newly generated ISOs still require testing on the target Mac. Original source ISOs are not modified.
